# Pothik Web Frontend

Vite + React + TypeScript UI for Pothik (admin / web shell).

Monorepo: [github.com/monir4724/Pothik](https://github.com/monir4724/Pothik)

## Setup

```bash
npm install
npm run dev
```

Default Vite URL is usually **http://localhost:5173**.

## Scripts

| Script | Purpose |
| ------ | ------- |
| `npm run dev` | Dev server + HMR |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Preview production build |
